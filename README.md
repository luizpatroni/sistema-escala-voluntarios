# Sistema de Apoio à Organização de Escalas de Voluntários

## Projeto Integrador II - Tecnologia da Informação

### Descrição

Este projeto tem como objetivo auxiliar na organização das escalas de voluntários de uma comunidade religiosa, automatizando um processo que atualmente é realizado manualmente. A aplicação permite o cadastro de voluntários e a geração de escalas de forma simples e organizada.

### Objetivo

Desenvolver um sistema computacional capaz de apoiar a elaboração de escalas de voluntários, considerando critérios de organização, praticidade e facilidade de utilização pelo coordenador responsável.

### Tecnologias Utilizadas

- Python 3
- Flask
- SQLite
- HTML

### Funcionalidades

- Cadastro de voluntários
- Armazenamento dos dados em banco SQLite
- Geração de escala mensal
- Interface web simples
- Estrutura preparada para futuras melhorias

### Como Executar

1. Instale as dependências:

```bash
pip install -r requirements.txt
```

2. Execute a aplicação:

```bash
python app.py
```

3. Abra o navegador e acesse:

```text
http://127.0.0.1:5000
```
